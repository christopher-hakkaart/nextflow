# `shifter`

The `shifter` scope controls how [Shifter](https://docs.nersc.gov/programming/shifter/overview/) containers are executed by Nextflow.

##### `shifter.enabled`

Execute tasks with Shifter containers (default: `false`).

##### `shifter.envWhitelist`

Comma-separated list of host environment variable names to export to the container environment. Each variable is read from the environment of the machine that runs the task. To set a variable to a specific value, use the [`env`](./env) scope instead.
